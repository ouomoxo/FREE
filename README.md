# 선율 · SEONYUL

점과 선으로 짓는 하나의 세계.
*A world built from dots and lines.*

검은 화면 하나. 이미지도, 영상도, 라이브러리도 없다.
점(點)과 선(線), 그리고 0과 1만으로 지어진 여섯 개의 악장.

---

## 악장 · Movements

| | | |
|---|---|---|
| `000` | 序 **PRELUDE** | 하나의 점에서 태어나는 장(場). 파동이 지나가며 점을 깨운다. |
| `001` | 點 **DOT** | 1,600개의 입자가 흩어짐 → 격자 → 원 → 황금나선을 통과한다. |
| `002` | 線 **LINE** | 일곱 개의 선을 커서가 휘고, 재생선이 왼쪽에서 오른쪽으로 읽는다. 골짜기마다 음이 하나씩 태어난다. |
| `003` | 世界 **WORLD** | 대륙 폴리곤을 150×66 점 행렬로 래스터화. 표류하고, 스캔되고, 자오선에서 갈라지고, 호(弧)로 이어진다. |
| `004` | 形 **FORM** | 회전하는 환(環)에 위에서 빛이 떨어진다. 밝은 곳은 촘촘한 0과 1로, 어두운 곳은 숫자의 장(場) 속으로 흩어진다. |
| `005` | 餘白 **SILENCE** | 모든 것이 하나의 점으로, 그리고 하나의 선으로 돌아간다. |

## 도구 · Instruments

- **커서** — 점을 밀어내고, 선을 휘고, 환을 기울인다. 클릭하면 파문과 음(音).
- **스크롤** — 속도가 점을 늘이고 선율을 부풀린다. 스크롤 휠도 악기다.
- **숫자** — 좌표, 프레임 카운터, 이진수, 악장 인덱스. 모든 수치는 활자이자 리듬이다.
- **소리** — 우측 하단 `SOUND` 토글. WebAudio로 생성되는 드론과 5음계 발현음. 기본값은 침묵.
- **정적(靜)** — 4초간 아무도 움직이지 않으면, 작품이 스스로 연주를 이어간다.

## 구조 · Structure

```
index.html
assets/css/style.css
assets/js/mapdata.js   대륙 폴리곤 → 150×66 이진 행렬
assets/js/engine.js    캔버스 · 스크롤 지휘 · 포인터 · 신시사이저
assets/js/scenes.js    여섯 악장
assets/js/main.js      로더 · 리빌 · HUD 숫자 · 커서
```

의존성 없음. 빌드 없음. `index.html`을 열면 그것으로 전부다.

각 악장의 sticky 프레임이 뷰포트 하나만큼 이동하는 구간과 씬의 크로스페이드 구간을
정확히 일치시켜, 글자와 그림이 하나의 몸으로 움직인다.
수천 개의 점은 열 개의 알파 밴드로 묶여 열 번의 `fill`로 그려진다.
